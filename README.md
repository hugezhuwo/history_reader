# 有趣的阅读 · 本地历史阅读器 MVP

## 启动

在本文件夹双击 **启动阅读器.command**，浏览器打开 http://127.0.0.1:8765 。运行时保留终端窗口，停止时按 Control+C。也可以在终端执行：

```sh
cd ~/Desktop/有趣的阅读/阅读器
../.venv/bin/python server.py
```

原书保存在 `../书本/`，不会修改原 PDF。第一次打开默认 PDF 第 31 页，之后记住上次页码。页码输入框按回车或移出焦点即可跳转。可尝试第 61 页地图、第 101 页翻译与地图。总计 1009 页，正文有文本层；封面等纯图片页显示无文本层提示，第一版不含 OCR。

## 两个功能

- **翻译**：每次只提取当前页文字，识别当前页全部引文（包括短引文、中英文引号、嵌套和跨页可见部分），不再限制每页 6 段。点击原页段落，可翻译该段。所有引文立即列出，然后逐段机翻；长引文分段处理。右栏桌面宽度 320px；窄屏移到底部。使用 PyMuPDF 渲染原页并叠加可点击文字区域，不依赖外部 PDF CDN。没有自由拖选文字功能。
- **地图**：仅匹配书内 `地名（今省份地点…）` 等说明，和全国市县现代参考点核对（`modern_places.json`，`places.json` 为旧称补充）。第 61 页可以看到濮阳、任城、东平，第 101 页可以看到当阳、夏口。保留现代说明、原句和 PDF 页码。未匹配的地点不标。底图离线，不发在线地理编码请求；加入当代省界，省名不标出，按当前页向前累计最近 10 页。地点去重，保留全部出现页码，可点击跳回。书中地名直接显示在地图上，相近地点共用标签框，标签之间自动避让并连线指向位置；可放大地图查看。

## 翻译模型与替换

默认本机 MLX + Qwen2.5-3B-Instruct-4bit，模型在 `model-3b/`（原 1.5B 模型仍保留在 `model/`），独立环境在 `../.model-venv/`。书页不上传，下载模型之后离线可运行。每个片段独立进程推理，首次较慢；同一书页、原文、模型配置的结果缓存到 `cache/`。刷新命中缓存。清空此目录可重算。

`model_worker.py` 是本地模型适配器；`server.py` 中 `translate()` 是统一入口。也可使用兼容 Chat Completions 的接口：

```sh
export LLM_BASE_URL=http://127.0.0.1:11434/v1
export LLM_MODEL=qwen2.5:7b
# 如接口需要密钥，再设置 LLM_API_KEY
../.venv/bin/python server.py
```

配置远程接口后，当前所选片段和当前页上下文会发到该接口。默认不启用远程接口。

## 当前局限（没有伪造占位译文）

- 自动识别是引文规则，不是完整古文分类器，可能漏检、误检；无引号古文可点击段落翻译。单段最多 1800 字。
- 本地小模型译文可能错误，尤其数字比例、专名和制度术语；它是阅读辅助，不能替代原文。模型不可用时显示失败提示，不把原文或字典替换当译文。
- 地点表为全国现代行政区参考点；未注释的历史地名只列入待查，不直接当作现代同名地点。坐标为现代市县行政中心参考，不是历史治所精确位置；“南”“东北”等方向不推算为古址坐标。只标市级位置参考，不保证古址精度。
- 地图包含当代省界和现代参考点，不显示省名，没有历史边界。地名标签进行碰撞避让，同一位置的多个地名合并到标签框分行显示，详细地名保留在列表。大地图通过“放大地图”打开。
- 翻译只处理当前页（读取前后各一页以判断跨页引号），地图累计当前页及之前 9 页，不预分析整书。翻页可立即读原页，但已开始的推理仍会在后台完成；后端串行推理以控制内存。
- 本地服务只监听 127.0.0.1，适合本机单人使用。书籍可从侧栏切换，支持工作区根目录及书本/书籍目录中的 PDF。

## 文件

`server.py` 本地服务/PDF/抽取；`model_worker.py` 模型；`index.html`、`app.js`、`style.css` 界面；`places.json` 现代参考点；`china.json` 离线底图；`test_reader.py` 实书回归检查。

```sh
../.venv/bin/python -m unittest -v test_reader.py
```

依赖：Python 3.9+ 和 requirements.txt；本地模型需 Apple 芯片、Python 3.12 和 requirements-model.txt。本机均已安装。模型来源：https://huggingface.co/mlx-community/Qwen2.5-3B-Instruct-4bit ，推理：https://github.com/ml-explore/mlx-lm 。底图为 Natural Earth 110m admin countries（public domain）：https://github.com/nvkelso/natural-earth-vector ，保留 China / Taiwan 两个要素，仅作阅读定位示意。

1. 去掉古文字词筛选和“每页最多 6 段”限制，短引文也列入。引文规则不能判断是否属于古文，所以现代引文与术语也可能被解释。跨页引文只翻当前页可见部分；可点击整个正文段落。所有卡片立即列出，排队机翻。
2. “生僻字 · 候选读音”使用离线 pypinyin。提示来自小型疑难字表与 CJK 扩展区，**不能穷尽生僻字**；保留原始 Unicode，可手动输入当前页任何字词。多音字显示候选读音，不声称已确定人名读音。无字库覆盖的扩展字可能仍缺字形，原 PDF 图像保留原字。
3. 每段“联网查证”才联网。字词先查汉典释义，引文通过维基文库检索原典，显示真实链接与返回片段。只发送该字词或引文的检索短句，不自动联网整页。再点击“依据来源辅助释义”，本地模型结合来源生成独立的辅助释义，基础机翻仍保留。没有来源时不伪造结果；来源未必提供现代译文，也不保证能解释所有制度或典故。网络失败不影响本地机翻。联网结果落在本机缓存，可删除 cache 下 *.research.json 清理；查证按钮会重新检索。
4. 地图范围为 `[当前页-9, 当前页]`，最早从第 1 页开始。只扫这 10 页文字，原有保守定位规则不变。现代省界离线保存为 `provinces.json`，来源：阿里云 DataV 行政区域边界 `https://geo.datav.aliyun.com/areas_v3/bound/100000_full.json`（2026-10-28 下载，用于阅读位置参考，不作为测绘依据）。
5. 地图编号和省名共用碰撞检测；标签必要时移开并连回参考点，同坐标或极近点合并编号。表中保留各地名及出现页码，可打开大地图和回跳原页。只画省级区划线，不标省名。书中地名直接标在地图上，小侧栏空间有限，可用“放大地图”。

联网文档：`https://www.mediawiki.org/wiki/API:Search`；字典链接：`https://www.zdic.net/`。本机运行仍为 `../.venv/bin/python server.py`。

### 地图标签布局修正

地名标签固定放在地图左右两侧的专用空白栏，不再放在中国轮廓内部。中央保留省界和地点圆点，引线连接两侧地名。标签按南北顺序排列，长名字换行，点位最后绘制以保持可见。地点多时增加画布高度，不把标签挤回地图；可在放大地图中滚动查看。

### 连续滚动与侧栏

PDF 可直接向下/向上滚动阅读。界面只保留三页，通常是当前页及前后各一页；在书首/书尾使用最接近的三页。滚动切换当前页后自动补页、移除远页，并保持可见内容的位置；翻译和最近 10 页地图跟随当前阅读页。邻页只读取文本和图像，不自动启动翻译。仍可在侧栏输入页码跳转。

顶部标题栏已移到右侧栏。拖动阅读区和侧栏之间的竖条可调宽（180–640px，且不超过窗口宽度的 45%），竖条也支持左右方向键；点击“收起”可隐藏侧栏，再点击右上角“阅读工具”展开。宽度、开合状态和页码会记住。窄窗口默认收起侧栏，展开后占据右侧独立列，PDF 同步缩到左侧，不覆盖正文。

### 多本书

在侧栏“书籍”下拉框切换 PDF，每本书独立记住阅读页码。新增 PDF 后点旁边的刷新按钮，无需改代码或重启。书架读取“有趣的阅读”根目录的 PDF，以及“书本”“书籍”子目录内的 PDF。书籍切换会清空旧书的阅读窗口、翻译和地图，翻译/查证缓存按书籍文件指纹隔离。侧栏宽度和开合状态作为全局偏好保留。

### 阅读空间微调

所有窗口宽度下，展开侧栏都采用左右分栏，不覆盖 PDF。侧栏宽度最多占窗口 45%，窄窗口默认收起；桌面宽度偏好会保留。页与页之间只留 4px 间隔，不再显示页底页码标签，当前页仍显示在侧栏页码控件中。
