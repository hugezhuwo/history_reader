# 给 Codex 的 GitHub 连接授权仓库

本教程依据当前插件设置页面核对。账号连接和代码仓库访问权限是两个不同设置；已经连接账号时，不要仅因提交失败就反复断开重连。

## 当前页面上的正确入口

1. 打开「插件设置 → GitHub → GitHub」。
2. 在「已连接的账户」中确认 GitHub 用户名是拥有目标仓库的账号。本项目示例为 `hugezhuwo`。
3. 找到下方的「代码仓库访问权限」。
4. 点击该行右侧的 **「在 GitHub 上配置」**。

这里不需要点击「连接另一个账户」，也不需要先断开现有账户。无需让助手操作你的浏览器。

## 跳到 GitHub 之后

后续页面取决于 GitHub 当前授权状态，按实际显示操作：

1. 确认当前 GitHub 登录账号及安装目标账号正确。若先出现应用或账号选择页，选择与这次连接对应的 OpenAI / ChatGPT 应用，以及拥有目标仓库的账号。
2. 若出现 Repository access（仓库访问范围），可选择 Only select repositories（仅选择部分仓库）。
3. 将 `history_reader` 加入可访问仓库列表，无需为此开放其他仓库。
4. 按页面实际显示点击 Save、Install 或 Authorize 完成。不要只选中仓库而忘记保存。
5. 如果页面提示有待接受的权限更新，先阅读其范围，再决定是否接受。
6. 回到原对话，让助手重新测试能否提交。能读取公开仓库或看到“已连接”，不代表写入已经成功。

如果跳转后的页面没有仓库选择、找不到该仓库，或仍然写入失败，请停在该页面提供截图，让助手按实际界面继续排查；不要随意修改无关应用或提供密码、令牌、验证码。

## 与 Chrome 登录的关系

你在 Chrome 登录 GitHub 可以保持不变。插件连接通过独立授权访问 GitHub，完成上述步骤不等于把浏览器控制权交给助手。

## 发布内容的边界

仓库访问授权成功后，仍只提交已经检查的源代码、教程和配置示例。书籍、模型权重、个人配置及阅读缓存不随项目发布。
